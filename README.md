# Lucem Services

Static GitHub Pages-ready website for `www.lucemservices.com`.

## Publish

1. Create or connect the GitHub repository for this site.
2. Push the contents of this folder to the repository root.
3. In GitHub Pages settings, deploy from the main branch root.
4. Ensure DNS for `www.lucemservices.com` points to GitHub Pages.

## Files

- `index.html`
- `styles.css`
- `main.js`
- `CNAME`
- `.nojekyll`
